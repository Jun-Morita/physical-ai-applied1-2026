# physical-ai-applied1-2026

Physical AI 2026 応用編1の最終課題として、**人のゲームパッド操縦から学ぶAIの着陸**に取り組むリポジトリです。
実在機を模擬したシミュレータで手動操縦のデータを収集し、模倣学習による着陸を目指します。

## タスクと使用機体

滑走路が視界に入っている最終進入から着陸するタスクを扱います。
空港は **羽田空港（HND / RJTT）**、機体は次の2機種に決定しました。

| 区分 | 機体 | 採用予定のモデル |
| --- | --- | --- |
| 旅客機 | Boeing 747-400（GE CF6-80C2B1F） | LincolnWorks-FlightGearの747-400 |
| 戦闘機 | F-14B | Zaretto系FlightGearモデル |

モデルは再現度の根拠を追えることを重視して選定しました。手元での動作・性能は未検証です。
選定理由と制約は [機体選定](docs/aircraft-selection.md) に記録しています。

初期の実装範囲は、最終進入からフレア、接地、減速までを想定しています。
使用する滑走路と進入方向は未選定です。空港・滑走路・天候・初期状態・機体は設定ファイルから変更できる設計にします。

## 技術構成と開発環境

- 利用可能な環境：Ubuntu、NVIDIA RTX 3060、ゲームパッド。
- Pythonの環境構築・依存関係管理：**uv**。
- シミュレータ構成案：JSBSimによる飛行物理とFlightGearによる表示。機体システムとの連携を確認して構成を決定します。
- データ収集：ゲームパッドの操縦入力と機体状態を時刻を揃えて記録します。
- 学習方法：手動操縦データによる模倣学習を軸にします。AIの入力は数値状態から始める案で、画像入力の採否は未定です。

Pythonのバージョンと依存パッケージは、採用するツールの互換性を確認して決定します。
環境構築時に `pyproject.toml` と `uv.lock` を管理し、このREADMEにセットアップ・実行手順を追記します。

## 現在の状況と開発予定

課題要件・機体選定・シナリオ設計方針を整理した段階です。
環境構築、機体・空港モデルの動作確認、データ収集、学習は未実施です。

1. 両機と羽田のモデルを導入し、ゲームパッドで操縦・着陸できることを確認する。
2. シナリオ設定、初期状態へのリセット、飛行データの記録・再生を実装する。
3. 操縦データを収集し、飛行単位で学習用・評価用に分割して模倣学習を行う。
4. 未使用の初期条件で、着陸成功率・接地位置・降下速度・姿勢・滑走路逸脱を評価する。
5. 提出用の動画・レポート・コードを整理する。

合意事項と未確定事項の詳細は [プロジェクト方針](docs/project-plan.md) を参照してください。
