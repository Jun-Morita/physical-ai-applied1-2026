# 最終課題の要件

出典：受講者から提供された「Physical AI応用1講座 最終課題（10/8版）」の画像5枚（2026-10-11受領）。
以下は画像の内容の要約です。日程・提出方法などの予定事項は、提出前に講座の最新案内を確認してください。
9/17版からの主な変更点は末尾に記載しています。

## 課題概要・技術要件

課題名：AI×ロボティクスによる創造的タスクの実現。

AI技術を活用し、ロボットが実行するタスクを設計・実装することで、創造性と技術力を発揮します。
対象はPhysical AI 応用1講座の受講者です。タスクは参加者が自由に設定できます。

- 何らかの形でAIを使用することが必須です。推論のみでもよく、学習は任意です。
- 講義で使用したROSとGazebo、Genesisなどのロボットシミュレータの使用を想定していますが、他のツールの使用や実機を動かしての撮影も可能です。
- 本リポジトリでは、受講者の方針としてPython環境構築にuvを使用します。

## 提出方法（予定）

「omnicampusでの提出」と「YouTubeへの動画アップロード」の両方を行います。

### omnicampusでの提出

omnicampusの提出口から以下を提出します（`omnicampusアカウント名` は自分のアカウント名に置き換える）。

1. レポート（PDF形式）：ファイル名は `説明資料_PAI最終課題_omnicampusアカウント名.pdf`。
2. GitHubのリポジトリURL：使用したコード一式。公開設定は必ず「public」にする。

### YouTubeでの動画提出

MP4動画を自分のYouTubeアカウントにアップロードし、URLをomnicampus上の指定フォームに提出します。

| 項目 | 条件 |
| --- | --- |
| 長さ | 1〜3分（2倍速再生可。倍速の場合は動画内または概要欄に明記） |
| タイトル | `PAI最終課題_omnicampusアカウント名` |
| 公開設定 | 限定公開が必須（最低条件）。全体公開を推奨し、優秀生選出時の加点対象。限定公開でも優秀生選出は可能 |
| 子ども向け・年齢制限 | どちらも「いいえ」を選択 |
| インスタントプレミア公開 | チェックしない |
| 予約公開 | 利用する場合は提出締切までの公開日時を設定 |
| 採点完了まで | 動画を削除・非公開にしない |

### 注意事項・公開について

- レポート・コード・動画などの成果物に、氏名・所属・メールアドレスなどの個人情報を一切記載・映り込ませない。omnicampusのアカウント名は記載可。
- 優秀作品は、本人の許可を得た上で松尾研公式YouTubeチャンネルのプレイリスト等で公開予定。
- 提出物は受講者相互の学びのため、本コースの受講者に公開される可能性がある。受講者以外に公開できない秘密情報や個人情報は含めない。

## 評価基準

合格ライン：ロボットがタスクを実行している動画及び提出物を提出すれば合格。

加点要素：

- 創造性：独自性のあるアイデアやアプローチ。
- 技術力：高度な技術や複雑な制御の実装。
- 実用性：現実世界での応用可能性。
- 表現力：動画の構成や説明のわかりやすさ。

他人の作品の剽窃、最終課題サンプルの丸写し、明らかに関係のないファイルの提出などの悪質な行為は、講義の修了判定対象外となる可能性があります。

## 最終課題サンプル

画像に記載されたサンプルの題材と難易度です。URLは講座の案内を参照してください。
