# 最終課題の要件

出典：受講者から提供された「Physical AI応用1講座 最終課題（9/17版）」の画像3枚。
以下は画像の内容の要約です。日程・提出方法などの予定事項は、提出前に講座の最新案内を確認してください。

## 課題概要・技術要件

課題名：AI×ロボティクスによる創造的タスクの実現。

AI技術を活用し、ロボットが実行するタスクを設計・実装することで、創造性と技術力を発揮します。
タスクは参加者が自由に設定できます。

- 何らかの形でAIを使用することが必須です。推論のみでもよく、学習は任意です。
- 講義で使用したROS、Gazebo、Genesisなどの使用を想定していますが、他のツールも使用できます。
- 実機を動かして撮影することもできます。
- 本リポジトリでは、受講者の方針としてPython環境構築にuvを使用します。

## 提出物と提出方法（予定）

omnicampusで、ZIPファイルとGitHubリポジトリ（プロジェクトのURL）を提出します。

| 提出物 | 条件 |
| --- | --- |
| 動画 | ロボットがタスクを実行する様子を収録したMP4を1つ。長さは1〜5分。倍速再生可。ただし使用時は「2倍速」などと明記する。 |
| レポート | 課題の概要、目的、工夫した点などを記載した簡単なPDFを1つ。 |
| コード | 使用したコード一式をGitHubリポジトリで提出。講師側では動作確認を行わず、参考資料として扱う。 |
| ZIP | 動画とレポートを含める。アップロード容量の上限は200MB。 |

ファイル名の指定（`omnicampusアカウント名` は自分のアカウント名に置き換える）：

- 動画：`動画_PAI最終課題_omnicampusアカウント名.mp4`
- レポート：`説明資料_PAI最終課題_omnicampusアカウント名.pdf`

提出物は受講者相互の学びのため、本コースの受講者に公開される可能性があります。
公開できないデータは使用しないでください。

## 評価基準

画像に記載された合格ラインは「ロボットがタスクを実行している動画を提出すれば合格」です。
AI使用や提出物など、ほかの課題要件も満たす形で準備します。

加点要素：

- 創造性：独自性のあるアイデアやアプローチ。
- 技術力：高度な技術や複雑な制御の実装。
- 実用性：現実世界での応用可能性。
- 表現力：動画の構成や説明のわかりやすさ。

他人の作品の剽窃、最終課題サンプルの丸写し、明らかに関係のないファイルの提出などは、講義の修了判定対象外となる可能性があります。
